# Пользовательские сценарии Telegram-бота

Этот документ описывает текущие пользовательские пути в боте с точки зрения пользователя.
Ниже зафиксировано фактическое поведение по текущему коду, то есть MVP в его текущем виде.

## 1. Точка входа

### 1.1. Первый вход / возврат в бот

Путь:
`/start` -> приветственное сообщение -> `Главное меню`

Что происходит:
- Бот создаёт или подгружает пользователя.
- Язык пользователя берётся из базы, а если пользователя ещё нет, определяется по Telegram-профилю.
- Пользователь сразу попадает в `Главное меню`.

### 1.2. Возврат в главное меню текстовой кнопкой

Путь:
`Текстовая кнопка "Главное меню"` -> `Главное меню`

Что происходит:
- Если пользователь находится вне FSM-сценария и отправляет текст `Главное меню`, бот показывает главное меню.
- Если пользователь отправляет любой другой текст вне ожидаемого сценария, бот отвечает: "Я не понимаю. Выберите пункт из меню." и показывает кнопку `Главное меню`.

## 2. Главное меню

Текущие разделы главного меню:
- `Купить прокси`
- `Мои прокси`
- `Баланс`
- `Чекер`
- `FAQ`
- `Настройки`

## 3. Настройки

### 3.1. Смена языка

Путь:
`Главное меню` -> `Настройки` -> `Язык` -> `{Русский | English}` -> сообщение об успешной смене языка -> `Главное меню`

Возврат:
`Главное меню` -> `Настройки` -> `Язык` -> `Назад` -> `Главное меню`

Итог:
- Язык сохраняется в базе и в состоянии пользователя.
- После выбора языка пользователь всегда возвращается в `Главное меню`.

### 3.2. Настройка уведомлений

Путь:
`Главное меню` -> `Настройки` -> `Уведомления` -> `Смс о продлении` -> `{Да | Нет}` -> сообщение об успешном изменении -> `Главное меню`

Возврат:
- `Главное меню` -> `Настройки` -> `Уведомления` -> `Назад` -> `Главное меню`
- `Главное меню` -> `Настройки` -> `Уведомления` -> `Смс о продлении` -> `Назад` -> `Главное меню`

Итог:
- Флаг уведомлений сохраняется в базе и в состоянии пользователя.
- После выбора `Да` или `Нет` бот возвращает пользователя в `Главное меню`.

## 4. Баланс

### 4.1. Просмотр баланса

Путь:
`Главное меню` -> `Баланс` -> сообщение с текущим балансом -> меню баланса

Меню баланса:
- `Пополнить баланс`
- `Назад`

Возврат:
`Главное меню` -> `Баланс` -> `Назад` -> `Главное меню`

### 4.2. Пополнение баланса через крипту

Путь:
`Главное меню` -> `Баланс` -> `Пополнить баланс` -> `Крипта` -> `{5 | 10 | 15 | 20 | 50 | 70 | 100}` -> сообщение со ссылкой на оплату

Возврат:
- `Главное меню` -> `Баланс` -> `Пополнить баланс` -> `Назад` -> `Главное меню`
- `Главное меню` -> `Баланс` -> `Пополнить баланс` -> `Крипта` -> `Назад` -> `Пополнить баланс`

Итог:
- После выбора суммы бот присылает ссылку на оплату и подсказку "Чтобы открыть удобнее: зажми ссылку и выбери 'Открыть в'".
- Автоматического возврата в `Главное меню` после выдачи ссылки сейчас нет.

### 4.3. Пополнение баланса через СБП

Статус:
- В текущем меню этот путь скрыт.
- В коде есть заглушка "Заглушка для оплаты в СПБ", но кнопка сейчас не показывается пользователю.

## 5. Покупка прокси

### 5.1. Вход в сценарий покупки

Путь:
`Главное меню` -> `Купить прокси`

Развилки:
- Если баланс меньше `3`, бот показывает сообщение "Недостаточно денег на счету, пополнить?" и открывает меню баланса.
- Если баланс достаточный, бот запускает сценарий покупки.

### 5.2. Полный happy path покупки

Путь:
`Главное меню`
-> `Купить прокси`
-> `Выберите версию прокси`
-> `{IPv6 | IPv4 | IPv4 Shared}`
-> `Выберите тип прокси`
-> `{SOCKS | HTTP}`
-> `Выберите страну`
-> `{выбор страны}`
-> `Введите количество прокси`
-> `{количество}`
-> `Выберите количество дней`
-> `{количество дней}`
-> экран подтверждения с параметрами и ценой
-> `{Да, оплатить | Да, оплатить (с автопродлением)}`
-> `Успешная покупка`
-> список купленных прокси
-> `Главное меню`

Что пользователь получает после успешной покупки:
- IP:PORT
- тип прокси
- версия прокси
- страна
- логин
- пароль
- срок действия
- статус автопродления

### 5.3. Возвраты внутри покупки

Путь возвратов:
- `Выберите версию прокси` -> `Назад` -> `Главное меню`
- `Выберите тип прокси` -> `Назад` -> `Выберите версию прокси`
- `Выберите страну` -> `Назад` -> `Выберите тип прокси`
- `Введите количество прокси` -> `Назад` -> `Выберите страну`
- `Выберите количество дней` -> `Назад` -> `Введите количество прокси`
- `Экран подтверждения` -> `Отмена` -> `Главное меню`

### 5.4. Подсказка "Как выбрать?"

Путь:
`Главное меню` -> `Купить прокси` -> `Как выбрать?` -> справочный текст -> экран выбора версии прокси

Итог:
- Пользователь остаётся на шаге выбора версии и может продолжить покупку.

### 5.5. Ошибки и проверки в покупке

Система сейчас обрабатывает такие случаи:
- Введена страна не из списка -> бот повторно показывает выбор страны.
- Введено некорректное количество -> бот просит ввести корректное целое число больше нуля.
- Недостаточно прокси в наличии -> бот показывает, сколько доступно, и просит ввести количество заново.
- Введён недопустимый срок -> бот показывает ошибку и просит выбрать срок снова.
- Ошибка API -> бот сообщает об ошибке подключения к серверу.
- Недостаточно денег на этапе оплаты -> бот отправляет пользователя в меню баланса.

### 5.6. Ограничения по минимальному сроку

Текущее поведение по коду:
- `IPv6`: минимум `3` дня
- `IPv4` и `IPv4 Shared`: минимум `7` дней
- Максимум для всех: `90` дней

## 6. Мои прокси

### 6.1. Просмотр списка своих прокси

Путь:
`Главное меню` -> `Мои прокси` -> сообщение с количеством прокси -> карточки прокси -> меню действий

Что показывается по каждому прокси:
- IP:PORT
- тип
- версия
- страна
- логин
- пароль
- срок действия
- включено ли автопродление

Если прокси нет:
`Главное меню` -> `Мои прокси` -> "У вас нет прокси" -> меню:
- `Купить прокси?`
- `Назад`

### 6.2. Скачать список прокси в `.csv`

Путь:
`Главное меню` -> `Мои прокси` -> `.csv` -> бот отправляет файл -> `Главное меню`

Итог:
- Пользователь получает документ со списком прокси.
- После отправки файла бот возвращает в `Главное меню`.

### 6.3. Скачать список прокси в `.xls`

Путь:
`Главное меню` -> `Мои прокси` -> `.xls` -> бот отправляет файл -> `Главное меню`

Итог:
- Пользователь получает документ со списком прокси.
- После отправки файла бот возвращает в `Главное меню`.

### 6.4. Отключить автопродление

Условие показа:
- Кнопка появляется только если у пользователя есть хотя бы один прокси с включённым автопродлением.

Путь:
`Главное меню` -> `Мои прокси` -> `Отменить автопродление` -> список прокси с автопродлением -> `{выбор proxy IP:PORT}` -> сообщение об успехе

Дальше:
- Если в списке ещё остались прокси с автопродлением, бот снова показывает список на выбор.
- Если таких прокси больше не осталось, бот возвращает пользователя в `Главное меню`.

Возврат:
`Главное меню` -> `Мои прокси` -> `Отменить автопродление` -> `Главное меню`

Примечание:
- На этапе выбора прокси возврат сделан через текстовую кнопку `Главное меню`, а не через inline-кнопку `Назад`.

### 6.5. Включить автопродление

Условие показа:
- Кнопка появляется только если у пользователя есть хотя бы один прокси с выключенным автопродлением.

Путь:
`Главное меню` -> `Мои прокси` -> `Включить автопродление` -> список прокси без автопродления -> `{выбор proxy IP:PORT}` -> сообщение об успехе

Дальше:
- Если в списке ещё остались прокси без автопродления, бот снова показывает список на выбор.
- Если таких прокси больше не осталось, бот возвращает пользователя в `Главное меню`.

Возврат:
`Главное меню` -> `Мои прокси` -> `Включить автопродление` -> `Главное меню`

Примечание:
- На этапе выбора прокси возврат сделан через текстовую кнопку `Главное меню`, а не через inline-кнопку `Назад`.

## 7. Чекер

### 7.1. Проверка статуса прокси

Путь:
`Главное меню` -> `Чекер` -> список прокси -> `{выбор proxy IP:PORT}` -> сообщение со статусом прокси -> повторный показ списка

Возможные результаты:
- `Прокси активно: IP:PORT`
- `Прокси не активно: IP:PORT`
- ошибка API

Возврат:
`Главное меню` -> `Чекер` -> `Главное меню`

Если прокси нет:
`Главное меню` -> `Чекер` -> "У вас нет прокси" -> меню:
- `Купить прокси?`
- `Назад`

Примечание:
- После проверки бот снова показывает список прокси для следующей проверки.

## 8. FAQ

### 8.1. Просмотр FAQ

Путь:
`Главное меню` -> `FAQ` -> текст FAQ -> `Главное меню`

Итог:
- Бот отправляет один текстовый блок с ответами на частые вопросы.
- Возврат оформлен сразу через inline-кнопку главного меню.

## 9. Полная карта возвратов

Кратко по основным маршрутам возврата:
- `Настройки` -> `Назад` -> `Главное меню`
- `Язык` -> `Назад` -> `Главное меню`
- `Уведомления` -> `Назад` -> `Главное меню`
- `Смс о продлении` -> `Назад` -> `Главное меню`
- `Баланс` -> `Назад` -> `Главное меню`
- `Пополнить баланс` -> `Назад` -> `Главное меню`
- `Крипта / выбор суммы` -> `Назад` -> `Пополнить баланс`
- `Покупка / выбор версии` -> `Назад` -> `Главное меню`
- `Покупка / выбор типа` -> `Назад` -> `Выбор версии`
- `Покупка / выбор страны` -> `Назад` -> `Выбор типа`
- `Покупка / ввод количества` -> `Назад` -> `Выбор страны`
- `Покупка / ввод дней` -> `Назад` -> `Ввод количества`
- `Покупка / подтверждение` -> `Отмена` -> `Главное меню`
- `Мои прокси / управление автопродлением` -> `Главное меню`
- `Чекер / выбор прокси` -> `Главное меню`

Ниже функции, которые уже доступны пользователю прямо сейчас:

- включение и выключение уведомлений
- просмотр баланса
- пополнение баланса через крипту по ссылке
- покупка прокси
- просмотр своих прокси
- скачивание прокси в `.csv` и `.xls`
- отключение автопродления
- включение автопродления
- проверка статуса прокси
- просмотр FAQ

## 11. Наблюдения и ограничения текущей реализации

Важно зафиксировать как продуктовые заметки:

1. После выбора суммы пополнения бот отправляет ссылку, но не возвращает пользователя в `Главное меню`.
2. В FAQ указано, что минимальный срок прокси `30 дней`, но фактическая логика покупки сейчас другая: `3` дня для `IPv6` и `7` дней для остальных.
3. В FAQ упоминается сценарий "Продлить", но отдельного пользовательского пути продления сейчас нет. Есть только включение и отключение автопродления.
4. Для выбора страны, чекера и управления автопродлением используются reply-клавиатуры с текстовыми кнопками, а не единый inline-паттерн навигации.
5. Путь оплаты через СБП в коде есть как заглушка, но в интерфейсе сейчас недоступен.
6. В разделе `Мои прокси` нет отдельного экрана деталей; пользователь сразу получает весь список прокси сообщениями.
